1. تمهيدية انحفاظ النورم الجبري (Norm Preservation)

في حلقة الامتداد \(\mathcal{R} = \mathbb{Z}_{M_p}[\sqrt{3}]\)، لـ \(z = u + v\sqrt{3}\) مع النورم \(N(z) = u^2 - 3v^2\):

\[(u^2 + 3v^2)^2 - 3(2uv)^2 = u^4 + 6u^2v^2 + 9v^4 - 12u^2v^2 = (u^2 - 3v^2)^2\]

Lean 4: norm_preservation_invariant

2. برهان انحفاظ الباقي بترديد 6 (Mod-6 Reduction)

لكل \(k \ge 1\)، نثبت بالاستقراء الرياضي أن \(s_k \equiv 2 \pmod 6\):

\[s_1 = 4^2 - 2 = 14 = 6(2) + 2 \equiv 2 \pmod 6\] \[s_{k+1} = (6m_k + 2)^2 - 2 = 36m_k^2 + 24m_k + 2 = 6(6m_k^2 + 4m_k) + 2 \equiv 2 \pmod 6\] \[\implies m_{k+1} = 2m_k(3m_k + 2)\]

Lean 4: six_k_recurrence_invariant

3. برهان تشاكل تشيبيشيف التام (Chebyshev Isomorphism)

بتعريف المتغير الخطي \(X_k = 3m_k + 1 = s_k / 2\):

\[X_{k+1} = 3(6m_k^2 + 4m_k) + 1 = 18m_k^2 + 12m_k + 1\] \[2X_k^2 - 1 = 2(3m_k + 1)^2 - 1 = 18m_k^2 + 12m_k + 1\] \[ herefore X_{k+1} = 2X_k^2 - 1 = T_2(X_k)\]

Lean 4: chebyshev_step_equivalence

4. برهان مبرهنة حسّون للقفز اللوغاريتمي الفائق

لأي معادلة \(x = a + b x^n\) في أي حلقة تبديلية \(R\):

\[x - a = b x^n \implies (x - a)^{2^m} = (b x^n)^{2^m} = b^{2^m} \cdot x^{2^m \cdot n}\]

Lean 4: hassoun_logarithmic_jump

5. برهان قفز تشيبيشيف المزدوج (Degree-4 Composition)

\[T_4(X) = 2(2X^2 - 1)^2 - 1 = 8X^4 - 8X^2 + 1 = 8Y(Y - 1) + 1 \quad (Y = X^2)\]

Lean 4: chebyshev_double_jump
